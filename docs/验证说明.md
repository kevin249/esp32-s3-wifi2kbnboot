# 验证说明

## 软件检查

| 测试 | 内容 |
|---|---|
| 后端与HTTP测试 | ISO快照、目录限制、双LUN读取隔离、会话隔离、写后读与持久化、交接状态、上传限制、长连接与鉴权 |
| mtools集成测试 | 自动格式化文件盘、长文件名BIOS导入与导出逐字节比对；缺工具时明确跳过 |
| 页面事件测试 | 真实页面脚本的键盘与修饰键映射、网络在途时的鼠标释放、主板脉冲参数；不连接实际设备 |
| 真实C缓存测试 | 偏移、跨块、预读淘汰、尾块、64位地址、写入失效及LUN隔离 |
| ESP-IDF构建 | 固定工具链的真实编译与链接 |

## 必须上板验证的项目

1. 同一USB下识别两个逻辑盘：2048字节只读光驱和512字节可写U盘；键盘与相对鼠标可独立使用。
2. 网页键盘、鼠标、修饰键、组合键、Boot Mouse三字节报告、失去焦点释放和设备超时释放。
3. 从两个逻辑盘读取并比对数据；重点检查相同扇区地址不串盘、ISO尾块及不同读写尺寸。
4. 主机向普通U盘复制文件，安全弹出后网页取回并下载，比对哈希；反向上传BIOS并交还主机读取。
5. 主机持有文件盘时网页文件操作应返回409；设备尚未释放时禁止重新交还或用文件工具挂载。
6. UEFI和Legacy BIOS分别直接启动Windows、PE、Linux ISO，记录需要的SCSI命令及兼容性；Secure Boot单独验证。
7. 网络中断、短读、错误版本、写入失败与服务重启时，不能返回伪造数据或提前确认写入，键鼠任务不应被网络阻塞。
8. 异步读写期间USB重置、BOT reset和重插，确认旧完成事件不能完成新请求，旧写结果能使缓存失效。
9. 用示波器或逻辑分析仪确认PWR/RESET上电默认无效、短脉冲200毫秒、长脉冲5秒、忙时拒绝重复指令。
10. GPIO编号非法或冲突时应启动失败；GPIO为-1时接口拒绝动作。接好光耦后再测试真实主板，检查原机箱按键仍可用。

当前开发环境没有连接目标ESP32-S3和主板，没有宣称硬件项目已测通过。固件GPIO默认禁用，CI产物不能代替针对实际开发板配置后构建的固件。
