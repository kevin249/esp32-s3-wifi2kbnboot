# 验证说明

软件测试与硬件实测必须分开记录。持续集成编译成功只验证接口和依赖可构建，不能证明 USB 启动兼容性。

## 自动检查

| 检查 | 覆盖内容 |
|---|---|
| Python 单元与 HTTP 测试 | 数据边界、版本隔离、并发读、发布失败回滚、哈希校验、令牌、上传限制、长连接 |
| FAT32 集成测试 | 创建真实文件系统、加入 BIOS 文件、用 mtools 提取并逐字节比对；缺工具时跳过 |
| C 缓存测试 | 偏移复制、跨块拒绝、LRU、预读优先淘汰、磁盘尾块、清空、64位地址 |
| ESP-IDF 构建 | 固定 TinyUSB 与 IDF 版本的实际编译链接 |

## 上板验收步骤

1. 配置真实 Flash/PSRAM 参数并烧录，用原生 OTG 口连接测试电脑，确认枚举为键盘、鼠标、只读 U 盘，容量与后端一致。
2. 通过键鼠接口发送按下和释放，测试等待磁盘网络请求时键鼠仍响应，测试1.5秒超时释放。
3. 从虚拟 U 盘读取完整磁盘内容，与后端镜像逐字节或按哈希对比；覆盖尾块和不同读取尺寸。
4. 分别使用 UEFI 与 Legacy BIOS 启动 Ventoy；记录上电到菜单时间、主机重启到菜单时间和日志计数。
5. 使用 F2 启动内部硬盘上的 Windows、PE、Linux ISO，各自验证磁盘控制器驱动、文件系统及 Secure Boot 配置。
6. 上传测试 BIOS 文件但不刷新，确认旧版本仍可读；点击刷新，确认重新枚举后能读到新文件且内容完全一致。
7. 在大文件读取时上传，确认新旧版本不混读；不要在真实刷 BIOS 或系统安装期间触发刷新。
8. 模拟后端断网、HTTP超时、错误版本头、短读；未缓存读取应失败，不能返回零数据或卡死键鼠。
9. 在异步读取期间重插 USB，进行总线重置与 BOT reset，确认无旧缓冲区写入、无误完成新请求。
10. 检查目标主板的固件更新工具是否接受复合 USB 与只读介质；不接受时需要另行增加纯 MSC 模式或采用普通 U 盘。

当前交付环境没有连接 ESP32-S3 和目标主板，上述硬件项目均需实机验证，未宣称已测通过。没有提供可直接刷写到所有开发板的通用配置或性能保证。
