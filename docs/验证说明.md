# 验证说明

## 自动检查

- 页面真实脚本事件测试：键盘与修饰键、快速点击后的鼠标释放、PWR/RESET脉冲参数。
- C缓存测试：块内复制、跨块拒绝、LRU、预读淘汰、64位LUN地址、写入失效。
- C介质规则测试：名称、范围、大ISO分卷边界和大于2GiB的单卷偏移。
- 实际生产sd_media.c与ESP-IDF同版本FatFs原生集成测试：自动创建MBR/FAT32/exFAT、中文BIOS文件、模拟主机与网页的双向交接、ISO读取和失败时保留旧介质。
- ESP-IDF v5.5.2真实编译：FAT32正常构建、FAT32 BIOS纯U盘构建与exFAT正常构建。

## 上板验收

1. 检查SDMMC接线、3.3V供电、外部上拉与Flash/PSRAM/USB/GPIO冲突。无卡或格式错误时不得格式化SD卡。
2. 首次上电确认仅创建所选格式的文件盘镜像，原SD文件保留；重启后文件盘内容保留。
3. 正常配置识别两个逻辑盘及Boot键鼠；BIOS兼容配置只识别单逻辑盘普通U盘。
4. 网页上传厂商BIOS文件后交还主机，进入实际主板刷写工具验证读取。按厂商规则命名，先进行读文件验证。
5. 主机写文件、安全弹出后网页取回并下载；反方向上传并交还，逐字节或哈希比较。
6. 网页持有文件时交接应失败；主机持有卷时网页文件操作应拒绝。重复交接不得导致无意义重连。
7. 网页上传大文件时键鼠和GPIO仍能响应；网络断开不能使USB任务卡死。
8. 冷缓存、热缓存、随机读取、跨分卷和尾块均与原ISO逐字节比较。
9. 异步读写期间USB重置、BOT reset和重插，确认旧完成事件不误完成新请求。
10. 分别测试UEFI、Legacy BIOS、Windows/PE/Linux ISO与Secure Boot。基础MMC子集并不保证所有固件通用。
11. 确认PWR/RESET上电默认无效、短按200ms、长按5s；GPIO为-1时接口拒绝；GPIO电路先测量再接主板。
12. 检查掉电恢复与镜像损坏后的人工修复流程。不要在真实刷BIOS或安装过程中进行中断测试。

当前开发环境没有连接实际ESP32-S3、SD卡或主板；原生FatFs测试不是SD电气验证，编译通过也不是BIOS兼容性保证。视频采集仅有README中的架构说明，未实现视频采集驱动或网页视频流。
