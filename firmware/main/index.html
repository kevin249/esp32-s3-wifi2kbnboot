ISO 虚拟光驱

浏览 SD 卡 iso 目录，选择后直接挂载，不需要 Ventoy。

切换 ISO 前先取回文件盘。切换会短暂重连 USB，不要在安装或写入期间操作。

普通文件盘 · 双向传输

先在受控主机安全弹出文件盘，再取回到设备，随后可上传 BIOS 或下载主机写入的文件。

文件盘在 SD 卡上自动创建为带 MBR 的 FAT32 或 exFAT 镜像。主机使用期间禁止设备修改文件系统；支持根目录文件上传和下载。

主机按键

GPIO 默认禁用。先在固件配置引脚、有效电平并接好隔离驱动电路。长按通常用于强制关机，可能丢失未保存数据。
